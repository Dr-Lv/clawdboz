Bot @ 权限设置

配置哪些 Bot 可以 @ 其他 Bot。行表示发送者，列表示可被 @ 的目标。

提示：
• 勾选表示允许该 Bot 发送消息时 @ 另一个 Bot
• 权限是单向的：A 可以 @ B 不代表 B 可以 @ A
• 系统默认禁止所有 Bot 之间的 @ 行为

• 定时任务会在后台自动执行，执行结果通过 Bot 回复显示
